# Print Kings — Build Your Setup

## Purpose
The Setup Builder is the signature Print Kings experience. It converts a customer's business need into a recommended branded setup.

## Steps
1. What are you building?
   - Market
   - Event
   - Sports
   - Corporate
   - Roadshow
   - Retail
   - Hospitality
   - Product launch

2. How big?
   - Starter
   - Professional
   - Large
   - Custom

3. Core structure
   - Gazebo
   - Kiosk
   - Parasol
   - Banner wall
   - Promo counter
   - Custom/quote

4. Visibility
   - Flags
   - Banners
   - Pop-up displays
   - Banner walls
   - Pull-up banners

5. Complete the space
   - Tables
   - Chairs
   - Tablecloths
   - Promo counters
   - Other relevant accessories

6. Review
   - Selected products
   - Quantities
   - Price/estimate
   - Branding requirements
   - Add to cart
   - Request quote

## Architecture
Recommendations and compatibility rules must be data-driven. Avoid embedding recommendation logic throughout UI components.

## Future
A visual branded setup preview may be added later. MVP must not fake 3D/AI visualisation.
