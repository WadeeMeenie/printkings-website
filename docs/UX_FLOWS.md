1. BUILD YOUR SETUP
2. SHOP PRODUCTS
3. GET A QUOTE

## Homepage funnel
Brand promise → use-case selection → Build Your Setup → curated packages → shop categories → trust/operational explanation → quote CTA.

## Direct product journey
Discovery → category/search → product page → configuration → cart → customer details → delivery → artwork if required → payment → confirmation.

## Setup journey
Use case → setup size → core structure → visibility → furniture/completion → review → cart or quote.

## Corporate/bulk journey
Solution/use case → quote request → sales review → quote → customer acceptance → order → payment/production.

## Mobile principle
Mobile is a first-class commerce experience. Builder controls, product information, cart and checkout must be usable at common phone widths.

## UX rule
Do not make customers learn the supplier catalogue. Make the catalogue solve their business problem.
