# Print Kings — Design System

## Brand source of truth
The supplied Print Kings logo is the authoritative visual reference.

## Colour rule
Do not guess HEX values. Extract/verify the logo palette before freezing production colour tokens. Then validate contrast and define semantic tokens.

Planned tokens:
- primary
- primary-foreground
- secondary
- accent
- background
- surface
- text
- muted
- border
- success
- warning
- error

## Visual direction
Bold, professional, practical and energetic. Avoid generic cheap promotional-site styling.

## Typography
Use a strong commercial type system with explicit tokens for display, H1/H2/H3, body, labels, buttons, prices and metadata. Final font selection is part of brand validation.

## Components
Navigation, buttons, product cards, package cards, forms, price blocks, badges, tables, dialogs, upload components, builder steps, cart, checkout, status timeline.

## Photography
Prefer authentic product photography and realistic branded applications. Do not use fake product renders or misleading AI imagery as factual product photography.

## Accessibility
Colour contrast, keyboard navigation, focus states, readable type, semantic HTML and accessible form/error states are mandatory.

## Setup Builder identity
The builder should feel like a guided sales/configuration experience, not a generic multi-step form.
